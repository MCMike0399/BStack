# Delegation

Give each delegate the standing instruction "Answer direct questions directly. Don’t restate the request unless it helps resolve an ambiguity.", the engineering rules from the Burbi-mode skill, and the applicable role. A [Worker](../roles/worker.md) receives one bounded assignment with the selected playbook, the starting snapshot, writable scope, and acceptance check. Include the settled design constraints for implementation or the relevant method for an assignment to draft a design. An [Advisor](../roles/advisor.md) receives the question or fixed artifact, the criteria, and evidence. Supply them inline when the Advisor has no file tools. When [Coordination](coordination.md) applies, include the Coordination steps the delegate must follow in each brief.

1. **Choose the launch.** Use the [Worker](../roles/worker.md) or [Advisor](../roles/advisor.md) contract and the harness's available subagent capability. Check the launcher's effective tools, workspace isolation, and credential access against the assignment's required boundaries. If the launcher cannot enforce a required boundary or select a required model, hold dispatch and report the gap. Use a separate launcher only when it is authorized and meets the same requirements. Name the launcher used.
2. **Bind the handoff to the inputs.** Give the Worker the agreed starting snapshot and writable scope. When the assignment calls for independent review, start a fresh Advisor with the requirement, artifact, and relevant evidence. Keep the author's and parent's conclusions out of the brief. The parent records a snapshot ID for the exact candidate and any base or other input the review depends on. Include that ID with references to fixed versions the Advisor can read within scope, or include evidence inline from those same inputs. Ask the Advisor to return the supplied ID and identify what it covered and any gaps. List the checks already run on that snapshot with their results, and ask the Advisor to rerun one only when a finding depends on it.
3. **Check the result.** Check the returned artifact, changed paths, and evidence against the assignment. When relying on a review, confirm before integration that the report covers the question and the actual inputs match the reviewed snapshot. A missing or differing ID leaves review coverage unverified. If a relevant input changes, get a review of the new snapshot before relying on that coverage. For that round, start a fresh Advisor with the original brief, the new ID, and the previous report, unless the review needs state that lives in the earlier one and is costly to move. Reproduce material findings where possible and resolve them before integration. Rerun the acceptance check on the integrated result. Use [Coordination](coordination.md) for ownership and follow-ups across dependent assignments.

This assignment asks for a Worker fix and an independent review. Use a disposable copy of BStack's export fixture. A sequential retry leaves one row per export ID, and distinct IDs append in order. IDs are nonempty single-line strings. Keep the two-argument CLI and line-based output.

- **Worker brief.** Fix the retry defect in `export_worker.py` in the assigned copy at the supplied base. Read the fixture guidance and the supplied Bug fix playbook. For this example, the sandbox limits writes in the project copy to `export_worker.py`. The parent replays `job-17`, `job-17`, `job-19`, `job-17` through the CLI and expects `job-17`, `job-19` in that order. Return the change, any checks you ran, and any gaps.
- **Advisor brief.** Review the frozen base and candidate against that requirement. The parent computes the ID for these NUL-free source files as SHA-256 of the base bytes, a zero byte, and the candidate bytes. Give the evidence-only Advisor that ID, the diff, and the candidate source inline. Return the supplied ID, findings, and coverage gaps. For any predicted regression, give the ordered CLI inputs and expected and predicted rows so the parent can replay it.
- **Parent check.** Confirm the Worker changed only the assigned file and replay the CLI on its candidate. Reproduce material findings independently. Recompute the snapshot ID from the base and the bytes about to be integrated. Compare it with the review brief and returned report, then rerun the replay on the integrated copy.
