# Long-running work

With a selected playbook, do steps 1 and 2 before the playbook's first change, apply steps 3 and 4 to each unit of the playbook's work, and do step 5 before the final report. When no playbook fits, follow these steps in order.

1. **Frame the run.** Keep a decision log in a file the user names, otherwise outside the project tree, and give its path in every progress report. State the finish condition as a check that can pass or fail on the real product. Estimate the scope and name the blockers you found while reading. Identify irreversible or shared effects and the approval each needs. Record this framing in the log before changing project files. Do not wait for the user to confirm the framing. When a decision the user owns or an approval is missing, record it in the log, pause only the work that depends on it, and continue the rest.
2. **Design the phases.** Split the work into units that can each be verified on their own. Put the riskiest unknown first. Prepare the check for the finish condition before the first unit's change, and record its baseline. Run units in parallel only when they have separate write targets. Delegate units only when the user asked to delegate. Record the phase list in the log.
3. **Run each unit as an experiment.** State what the unit should change and how you will observe it. Make the change and check it on the real artifact. Keep the change if the check shows progress. If the check fails, undo only that unit's change and record why. If the check is inconclusive, record the unit as unverified and do not build on it. Check delegated work against its artifact, not its report. If a check is wrong, correct it as its own step before relying on it.
4. **Update the log.** As each unit finishes, record the decision, the evidence, rejected alternatives, and anything left for the user. When the run stops, record the checkpoint and the condition for resuming.
5. **Hand back.** Check the whole result against the finish condition. Report the phases, what is verified, the path to the log, and what remains open.
