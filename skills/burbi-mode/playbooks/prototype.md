# Prototype

1. Name the design decision and an observation that could change it. Choose the least expensive form that can produce that observation. Use a working example when the interaction or runtime behavior is what matters.
2. When a working example is needed, build it outside the project tree or at the prototype location the user requests. When comparing alternatives, use meaningfully different approaches and the same realistic example for each.
3. Exercise the deciding case and describe what you observed, what you inferred, and what remains uncertain. Recommend an option and give the user the prototype or its location when it is part of the deliverable. Finish at the design decision.
